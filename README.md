# AI Multi-Translator

> **Experience powerful AI translation supporting 200+ languages with complete privacy**

A modern, sophisticated AI-powered translation app built with Next.js featuring a beautiful glass-morphism UI. It uses pre-trained language models from [Hugging Face](https://huggingface.co/) that run entirely in your browser - no data leaves your device, no API keys required, completely offline-capable.

## Features

- **200+ Languages**: Support for a vast array of languages and writing systems
- **Complete Privacy**: All processing happens in your browser - no data transmitted
- **Modern Glass-morphism UI**: Beautiful, responsive design with smooth animations
- **One-Click Copy**: Easy copying of translations to clipboard
- **Offline Capable**: Works without internet after initial model download
- **Zero Setup**: No API keys or configuration required

## UI Highlights

- **Glass-morphism Design**: Sophisticated translucent cards with backdrop blur effects
- **Gradient Backgrounds**: Beautiful layered gradients creating visual depth
- **Smooth Animations**: Fade-in, slide-up, and scale transitions for enhanced UX
- **Interactive Elements**: Hover effects and micro-interactions throughout
- **Responsive Layout**: Seamless experience across desktop, tablet, and mobile

## 🏃‍♂️ Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/tbold/ai-multi-translator.git

# Navigate to project directory
cd ai-multi-translator

# Install dependencies
npm install

# Start development server
npm run dev
```

### Open in Browser
Navigate to [http://localhost:3000](http://localhost:3000) to see the app in action.

## 🎯 How It Works

1. **Model Loading**: On first visit, AI models are downloaded and cached in your browser
2. **Local Processing**: All translation happens locally using WebAssembly and ONNX
3. **Multi-Language Support**: Translate text into multiple target languages simultaneously
4. **Privacy First**: No data transmission - everything stays on your device

## Development

```bash
# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
